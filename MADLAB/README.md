
  # Mobile UI/UX Design

  This is a code bundle for Mobile UI/UX Design. The original project is available at https://www.figma.com/design/6ab3TaA73xj6QL08E22T6r/Mobile-UI-UX-Design.

  ## Running the code
  cd backend
  uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
cd mobile-app
  Run `npm i` to install the dependencies

  Run `npx expo start` to start the development server.
